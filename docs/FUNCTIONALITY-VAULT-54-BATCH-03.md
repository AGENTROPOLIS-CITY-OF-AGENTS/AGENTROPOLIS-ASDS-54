## Integration

ASDS-54 owns shared interfaces, component registry, renderer adapters and visual conformance fixtures. CREATOR-CORE consumes the registry to produce a typed SceneIntent/ComponentRequest, including reference fidelity and media provenance. CONSTRUCTION resolves the request to a component implementation, builds it, runs unit/browser/visual/performance checks, and returns verified artifacts and receipts.

Status vocabulary: SPECIFIED -> IMPLEMENTED -> TESTED -> INTEGRATED -> DEPLOYED. BLOCKED is independent. Never auto-promote status. Existing particle/media capability IDs must be reconciled before adding duplicates.
